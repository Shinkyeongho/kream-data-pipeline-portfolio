# 데이터·확인 범위와 출처

## 원본 자료

프로젝트는 KREAM 스타일 합성 검수 데이터를 사용한 교육용 팀 프로젝트입니다. 사용자가 최종안으로 지정한 팀 저장소 ZIP, 최종 발표자료, 공급 원본 `data.zip`, 테이블·컬럼 명세 PDF를 기준으로 정리했습니다.

팀 공식 저장소: https://github.com/encore-ai-campus/mlo-02-p2-team4

## 이번 정리에서 직접 확인한 내용

- 원본 CSV 5개의 행 수·컬럼 수와 SHA-256을 확인했습니다. 모두 팀 최종 산출물의 원본 해시 기록과 일치했습니다.
- 원천 검수에서 달러 기호 표기 2,500행, `만` 포함 금액 2,500행, `초` 포함 시간 2,500행을 직접 집계했습니다.
- 소요시간이 정확히 `-999`인 값은 1,200행, 사번의 빈 문자열·`NULL`·`NA`는 각각 400행이었습니다.
- 입고 시각의 `Z` 또는 `+00:00` 표기는 2,500행이었습니다. 이는 해당 표기의 집계이며 모든 시간 컬럼의 UTC 표기 합계는 아닙니다.
- 명세와 SQL의 처리 구조를 읽고 대조했습니다. MySQL 적재·정제·최종 분류와 482개 검증 전체를 재실행하지 않았습니다.

이 직접 확인은 포트폴리오 정리 과정의 점검입니다. 프로젝트 당시 개인 단독으로 수행한 검사 실적으로 추가하지 않습니다.

## 명세와 구현 정책의 구분

| 항목 | 확인한 내용 |
| --- | --- |
| DBMS | 공급 명세는 PostgreSQL(public), 실제 구현은 MySQL입니다. 업무 기준을 MySQL 물리 구조와 적재 SQL로 구현했습니다. DBMS 선택 동기는 추정하지 않습니다. |
| 달러 환율 | 사용자 확인 기준으로 1달러 = 1,350원 고정입니다. 실시간 환율을 적용하지 않습니다. |
| 대표 판정 코드 | PDF에 기재된 3종 외에 공식 사전과 원본에는 `BOX_DMG_HOLD`도 있습니다. 실제 구현은 4종을 사용합니다. |
| 상세 정책 | 시간대 없는 값의 KST 간주, 정확한 대문자 `Y`만 재직 처리, 충돌 개정 양쪽 격리, 최고 유효 개정 선택은 기존 구현 정책에서 확인했습니다. PDF에 모두 명시된 규칙이라고 설명하지 않습니다. |
| 이전 유효 개정 선택 | 정책은 존재하지만, 기존 기록에서 불량 최신 개정 때문에 개정 1로 대체된 사례는 0건입니다. 정책과 발생 실적을 구분합니다. |

## 보유 자료와 공개 자료

원본 CSV는 보유하고 있습니다. 이 검토용 저장소에는 원본 CSV, 공급 명세 PDF, 전체 최종 내보내기 데이터, 과거·실행 코드를 포함하지 않았습니다. 설명 문서, 핵심 ERD, 집계 근거와 팀 최종 발표자료를 선별했습니다.

공개 구성은 전체 파이프라인 재현을 제공하지 않습니다. 기술 면접에서는 문서로 설명한 구조와 검증 범위를 확인할 수 있으며 실제 구현 코드를 직접 검토할 수 없는 한계가 있습니다.

## 기여와 출처 표기

MySQL 기반 Bronze → Silver 정제·적재는 개인 담당, Gold 해석을 위한 데이터 검증·추론은 참여 범위로 기재했습니다. 나머지는 공동 수행이며 Pandas 분석 코드는 다른 팀원 작성입니다. 개인 기여율이나 확인되지 않은 성능 개선율을 사용하지 않았습니다.

ERD·발표자료·기존 집계 파일은 팀 산출물입니다. 새로운 개인 설명 문서와 팀 산출물의 범위를 구분하며, 임의의 새 라이선스를 부여하지 않았습니다.
