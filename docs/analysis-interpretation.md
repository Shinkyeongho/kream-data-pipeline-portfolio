# Gold 결과를 해석하기 위한 검증

개인 기여는 Gold 분석을 위한 데이터 검증과 추론입니다. Gold 전체 구현과 다른 팀원이 작성한 Pandas 분석 코드를 개인 단독 성과로 설명하지 않습니다.

## 1. 최종 상태와 실제 작업 이력의 분모

| 지표 | 기준 | 건수 |
| --- | --- | ---: |
| 최종 검수 상태 | 검수별 최고 유효 개정 | 271,787 |
| 유효 작업 이력 | 최종 상태 + 이전 유효 개정 | 291,548 |

이전 유효 개정 19,761건은 현재 상태에서는 제외하지만 실제 수행한 작업 이력에 포함합니다. 현재 상태의 재검수 비중과 작업 이력의 재검수 비중을 같은 지표로 취급하지 않습니다. 중복과 오류 기록은 유효 작업량에 포함하지 않습니다.

## 2. 기간과 대상이 다른 분석

| 분석 | 대상 | 분모 |
| --- | --- | ---: |
| 일반 검수 위험 | 2022.01~2026.08 최종 상태 중 개정 1 | 243,454건 |
| 재검수 위험 | 2026.10월 최종 상태 중 개정 2 이상 | 21,656건 |

두 집단의 비율 차이를 운영 개선 전후의 효과로 해석하지 않습니다. 같은 개체·기간의 전후 비교나 개선안 적용 실험을 수행한 것은 아닙니다.

## 3. 높은 건수와 높은 오류율의 구분

저장된 재검수 분석에서 스니커즈검수1팀은 4,804건 중 3,753건(78.12%), 2팀은 3,733건 중 2,903건(77.77%)입니다. 여기서 분자는 재검수 분석 대상의 가품 오판정 코드 건수이며 전체 최초 검수 건수를 분모로 한 재검수 발생률이 아닙니다. 다른 부서도 유사한 비중을 보이므로 건수가 크다는 이유만으로 검수 능력이 낮다고 단정하지 않습니다.

근거: [재검수 부서 집계](../evidence/reinspection_department_risk.csv)

## 4. 짧은 검수시간과 품질 위험

저장된 일반 검수 집계에서 외주팀의 10분 미만 비중은 93.65%, 다른 부서는 28.78%입니다. 이는 시간 분포와 품질 위험을 함께 검토할 단서입니다. 짧은 시간이 오류를 발생시킨 인과관계를 입증한 결과는 아닙니다.

근거: [10분 미만 검수 집계](../evidence/general_duration_under10.csv), [일반 검수 부서 위험](../evidence/general_department_risk.csv)

## 5. 부서·인원·배상금의 의미

- 부서는 현재 정상 마스터 소속 기준입니다. 검수 당시 소속과 다를 수 있습니다.
- 등록 인원과 관측 사번 수는 실제 출근 인원이 아닙니다.
- 가품 오판정 배상금은 거래가 × 3으로 계산한 산식 기준 위험입니다. 실제 지급액·예방액·절감액이 아닙니다.
- 전문 셀 배정, 독립 재검수 등 운영 개선안은 제안입니다. 실제 효과는 추가 데이터와 시범 운영으로 평가해야 합니다.

## 다음 검증 과제

검사 당시 소속, 최초·재검수 실제 담당자, 근무표와 역량 이력을 확보하고 같은 기간·분모로 비교할 필요가 있습니다. 현재 자료만으로 개인의 능력이나 추가 채용 필요 인원을 확정하지 않습니다.
